# Scikit-Learn Mini Cases

Use this folder for short practice exercises after the Titanic and House Prices
baselines are running.

The goal is to repeat the same simple pattern on small datasets:

1. Load a dataset.
2. Split into train and test sets.
3. Train one baseline model.
4. Evaluate it with the right metric.
5. Change one thing and compare results.

## Suggested Mini Cases

### Classification

- Iris dataset: classify flower species.
- Breast cancer dataset: classify benign vs malignant tumors.
- Digits dataset: classify handwritten digits.

Models to try:

- Logistic regression
- Decision tree
- Random forest
- K-nearest neighbors

Metrics to practice:

- Accuracy
- Precision and recall
- Confusion matrix

### Regression

- Diabetes dataset: predict disease progression.
- California housing dataset: predict house values.

Models to try:

- Linear regression
- Ridge regression
- Decision tree regressor
- Random forest regressor

Metrics to practice:

- Mean absolute error
- Root mean squared error
- R2

## Simple Exercise Template

For each mini case, write down:

- What is the target?
- Is this classification or regression?
- Which features are used?
- Which model is the first baseline?
- Which metric tells the clearest story?
- What is one small improvement to try next?
